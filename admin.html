How to publish

  1. Click Download projects.json.
  2. Open your GitHub repo → Add file → Upload files → drop projects.json (replace the old one) → Commit changes.
  3. Wait about a minute, then refresh your site.

If you upload an image file, put it in assets/ in the repo and use its path, e.g. assets/my-thumb.jpg. Thumbnails you pick here are shrunk and saved inside projects.json automatically.
